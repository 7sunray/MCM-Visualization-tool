    What is MCM?

    Matrix chain multiplication

    Multiplying a long chain of matrices gives the same result however you group them, because matrix multiplication is associative. But the amount of work is not the same.

    Matrix chain multiplication (MCM) is the problem of choosing the order that needs the fewest scalar multiplications. You are not multiplying anything yet, only deciding where the parentheses go.

    Example · A 10×30 · B 30×5 · C 5×60

    • (A B) C10·30·5 + 10·5·604,500
    • A (B C)30·5·60 + 10·30·6027,000

    Same answer, 6× the work. With dozens of matrices the gap becomes enormous.

    • Optimal substructureThe best order for a chain is built from the best orders of its shorter sub-chains.
    • Overlapping subproblemsThe same sub-chains come up again and again, so we solve each one once and reuse it.
    • Dynamic programmingA table of sub-chain costs finds the best order in O(n³) time instead of trying every possibility.
